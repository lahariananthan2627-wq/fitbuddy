# Phase 4: Project Planning Phase
- **Tech Stack Selection:**
  - Backend Framework: FastAPI & Uvicorn
  - AI Models: Google Gemini 1.5 Pro & Gemini Flash
  - Database ORM: SQLAlchemy with SQLite (`fitbuddy.db`)
  - Frontend Templates: Jinja2, HTML, and CSS
- **Development Milestones:**
  1. Model selection & environment setup.
  2. Core backend logic (`routes.py`, database models, Gemini API wrappers).
  3. Frontend template creation (`index.html`, `result.html`, `all_users.html`).
  4. Local deployment and end-to-end testing.
